# plan · 计划与打卡

[![CI](https://github.com/james-kobe-curry/plan/actions/workflows/ci.yml/badge.svg)](https://github.com/james-kobe-curry/plan/actions/workflows/ci.yml)

plan 是一款中文 Android 应用，帮助你安排学习、健身和日常任务。输入名称就能建立任务，按需添加时长或数量目标，通过打卡、专注计时和历史记录回顾进度。

当前版本：**1.12.1**（版本号 16），支持 Android 8.0 及以上。应用名称为 **plan**，保留原有图标与签名，已明确选择的有效风格、色系和明暗模式继续保留；新安装或旧数据未选择风格时默认使用柔和。

## 本版更新

- **导入保留完整任务安排**：同一任务的历史版本与当前安排发生冲突时，保留本机整个任务系列，避免导入后重复安排；分类导入与并发的数据更新按同一事务顺序处理。
- **历史与统计一致**：修正提前开始、归档恢复后的历史筛选状态；旧数据存在重叠版本时，首页、复盘和进度卡按同一有效安排统计，原记录继续保留。
- **补齐损坏数据恢复入口**：「数据需要恢复」页面可从一键 ZIP 备份、全部数据 JSON 或本机命名／自动存档恢复，预览后确认。
- **提示不遮挡表单**：修正操作提示条在新打开窗口中遮挡按钮的问题，详情和历史中的快捷撤销继续可用。
- **专注保存失败保护**：计时状态无法保存时显示错误并恢复原状态，避免界面先显示成功或清除待保存的完成记录。
- **Android 8.0 兼容**：修正系统导航栏的兼容处理。默认柔和风格、原图标及已有功能保持不变。

## 功能

- **轻量任务**：新任务默认只记录是否完成，无需填写数量。需要时开启「添加进度目标」，记录分钟、页、题、次等进度；小时、公里支持最多两位小数。
- **个性资料**：在设置顶部编辑头像、昵称与首页寄语，选择是否在首页展示；相册头像会随当前全部数据与完整备份保存。
- **自定义分类**：最多建立 20 个分类，设置名称、底色和图标；任务可跟随分类图标，也可单独选择。删除分类后相关任务回到基础分类，归档与记录仍保留。
- **首页布局**：调整今日进度、任务列表、最近积累的顺序；进度与积累可隐藏，任务列表始终保留。支持简洁、详细两种任务密度，以及默认打开今日、计划、专注或记录。
- **计划安排**：选择执行星期、开始日期和可选截止日期；数量任务可设置长期总目标，并按执行天数分配每次目标。
- **计划提醒**：每项任务可选填提醒时间，按该任务的执行星期与有效日期提醒；通知支持「15 分钟后」和「今天不再提醒」，不会因此自动打卡。
- **休息与继续**：支持跳过今天并填写原因、撤销跳过、暂停与恢复安排；到期后可延期或归档，归档任务可选择日期恢复，保留之前的积累。
- **今日整理**：「今日安排」右侧更多按钮可整理顺序、折叠或展开已完成；任务卡右上角更多菜单可置顶、取消置顶或跳过今天。排序使用上下箭头，置顶任务在置顶区域内调整；首页、计划页、专注任务列表共用顺序，完成后点「完成排序」统一反馈。
- **每日打卡**：点击方框打开打卡窗口，普通任务确认完成，数量任务默认填写本次新增量；可单独修改当天总量，支持任务心得与撤销。
- **快捷撤销**：打卡、跳过与暂停后的底部提示可短时撤销上次操作，恢复原进度、心得或安排；之后已有冲突修改时保留新内容。
- **每日心得**：与任务打卡独立，每天最多一篇、每篇最多 5000 字，想写时再写；支持搜索、选择过去日期补写、编辑和删除，保存或删除均不影响完成率和专注统计。
- **草稿保护**：任务字段、打卡数字与心得自动保存为本机草稿；退出可选保留草稿、放弃修改或继续编辑，成功保存正式内容后清理草稿。
- **历史查询**：月历保留补记与修改；打卡明细可搜索任务标题和心得，专注明细显示每次任务、完成日期、时间与时长。明细支持全部、本周、本月和自定义日期筛选。归档任务及修改前的记录继续保留，同一天的最近打卡按更新时间排序。
- **归档回顾**：计划页区分「进行中」和「已归档」，点整张任务卡查看详情；「更多」中可暂停、恢复安排、延期或归档，按任务状态显示。任务详情展示安排变更、完成次数、打卡天数、专注时长与心得。归档内容也包含在计划备份和完整备份中。
- **专注计时**：常用时长默认 15/25/45/60 分钟，可增删并恢复默认，保留 1–8 项；也可自定义 1–1440 分钟。时间类任务带入目标时长，其他任务与自由专注使用上次手动选择；通知栏支持暂停、继续和结束，完成提醒可选择声音、振动或关闭。
- **提示音与测试**：默认使用清晨铃，另有轻木琴、清脆双音和柔和回响，可试听或导入自己的音频。「发送测试提醒」使用实际完成提醒的设置；「提醒状态」显示通知权限、静音、音量等相关状态。
- **兼容播放与诊断**：小米、Redmi、POCO 默认启用兼容播放，其他设备可手动开启。支持停止提醒声音，查看或复制最近一次测试/完成提醒的通知与播放器状态。
- **统计与进度卡**：查看打卡天数、累计专注和七日完成率；星期与日期分行显示，大字体时增加列宽，空间不足可左右滑动。每日进度卡与七日周报支持预览、点按查看大图和系统分享；每次打开默认每日、详细，任务名称与心得可选，图片跟随当前风格、点缀色与明暗模式。记录页通过三行导航进入每日心得、全部记录与月历、周月复盘。
- **周复盘与月复盘**：按周或月回顾完成、未完成、跳过、暂停、专注时长、分类进度与心得；当前阶段统计到今天，跳过和暂停不计入完成率分母。
- **分类备份与导入**：计划、记录、当前全部数据分别管理。计划和记录合并导入，重复内容略过，冲突时保留当前内容；同一任务的版本冲突按整个任务系列处理，避免产生重叠安排。全部数据恢复会替换当前数据，操作前提供预览并保留可撤销的副本。
- **一键打包备份**：一个 `.plan.zip` 文件保存当前计划与归档、个人资料与头像、自定义分类和图标、全部记录与每日心得、命名与自动存档、自定义提示音、提醒、主题与首页布局、常用专注时长。恢复前展示预览并校验完整性；ZIP 保持 v5，继续读取旧版 v1–v4，分类 `.plan.json` 文件仍可单独使用。
- **命名存档**：给当前计划与记录保存一个阶段快照，支持查看、改名、单独导出、恢复和删除。每份存档都包含当时的归档任务及完整记录。
- **自动存档**：有计划、记录、自定义分类或个人资料后，每天首次使用保存一份，独立保留最近 7 份，不占用 50 份命名存档名额；可查看、导出与恢复。
- **备份提醒**：首次有数据满 7 天且未成功导出完整 ZIP，应用内提示备份；可稍后再提醒或延后 7 天。成功完整导出后重新计时。
- **外观**：首页点「换肤」，先选清简、纸页或柔和，再选松绿、晴蓝、雾紫、柔玫瑰、暖杏或石墨点缀色，立即生效并自动保存；明暗模式独立设置。风格、点缀色和明暗模式均可随一键备份迁移。
- **集中设置**：「记录 → 设置」提供个人资料、数据与存档、计划与归档、分类管理、专注提醒、计划提醒、外观、首页布局及使用说明。
- **清晰的操作提示**：填写任务、目标或存档名称时，错误提示固定在弹窗可见区域，滚动表单也能看到。

## 快速开始

1. 在「计划 → 新任务」填写任务名称和执行星期，按需打开「添加进度目标」或「设置提醒时间」，再保存任务。分类与任务图标可按自己的习惯选择。
2. 在「今日」点任务的「待打卡」方框，确认完成或填写本次新增进度，核对保存后总量，再点「保存打卡」。想记下当天感受时，点「写心得」；已有内容时显示「看心得」。
3. 在「专注」选择任务和时长后开始计时；自定义时可勾选「保存为常用」，通过「管理」移除常用项或恢复默认。通过「专注提醒设置」选择提示音，可先试听，再发送测试提醒确认。
4. 在「记录 → 全部记录与月历」选择按日期、打卡明细或专注明细，搜索和筛选历史。
5. 在「记录 → 周复盘与月复盘」回顾阶段进度；点首页或「最近 7 天」旁的「分享」可调整每日或七日范围、样式，点预览查看大图，再通过底部「分享进度卡」分享；点「每日心得」回顾感受或选择日期补写。首页点「换肤」选择风格、点缀色与明暗模式；在「记录 → 设置」还能编辑个人资料、分类和首页布局。
6. 在「记录 → 设置 → 数据与存档 → 打开一键备份」打包保存全部积累；也可使用分类备份，在「我的存档」保存命名阶段，或查看「自动存档」。

## 关键规则

- 数量打卡默认填写**本次新增**。例如已记录 10 页，这次读了 5 页，填 5，保存后共 15 页。「修改当天总量」直接替换原数量，适合纠错或只改心得；两种模式的输入独立保留。
- 新任务、原任务编辑以及各日期的打卡分别保存草稿。没有修改的表单不产生草稿。成功保存正式内容后清理，保存失败时保留输入。草稿不计入统计，也不进入计划、记录、存档或完整 ZIP 备份。
- 任务或记录变化后，不适用的旧草稿会隔离提示。恢复全部数据、恢复阶段存档或撤销导入前，会先隔离当前草稿；再次打开对应表单时可查看并复制旧文字，不会自动套用旧单位或旧数量。
- 保存过程中中断、无法确认是否已经保存时，旧草稿只供查看和复制，不会自动续填或再次提交。请先核对正式任务或当天记录，避免重复新增数量。
- 仅修改任务名称、分类、图标或提醒时立即更新；目标、单位或日程变化会保留旧版安排。该任务今天已有打卡时，新安排最早明天生效；今天尚无打卡时最早今天生效。更晚的开始日期按所选日期执行；没有实质修改的保存不会增加版本。
- 更换单位会清空每次目标和已填总目标，需要重新输入；再次选择相同单位不会清空。
- 小时、公里可使用两位小数；页、题、次等单位使用整数。升级保留旧记录的真实数量与单位。
- 历史打卡仅针对所选日期已有安排的任务，未来日期不能打卡。修改计划不会把新目标套用到旧记录。
- 首页查看过去日期时显示「正在查看」日期栏，点「回到今天」即可返回当天；历史页面的进度与完成提示使用所选日期。
- 底部提示中的「撤销」仅用于最近一次打卡、跳过或暂停，不是连续回退。若对应记录、任务设置或相关状态之后已改变，会提示无法撤销，避免覆盖后续修改；其他任务的记录保留。提示消失后仍可从原入口修改打卡、撤销跳过或恢复安排。
- 跳过当天和暂停期间不计入应完成任务；跳过今天前需先撤销当天已有打卡。暂停时若今天已有打卡，则从明天停止安排，今天的进度仍保留。
- 恢复归档任务时选择今天或之后的日期，且不与旧安排和已有打卡重叠。已过期的原截止日期会清空，可在编辑中重新设置。
- 专注与任务完成量分别记录。完整计时计入专注统计，提前结束不计入；完成后仍需确认任务实际进度。
- 点击常用按钮或确认自定义时长会记住上次手动选择；任务目标自动带入不会覆盖这项记忆。普通任务、非时间目标及自由专注使用手动记忆，初始为 25 分钟。删除常用项或恢复默认列表不改变本次时长和上次手动选择。
- 进度卡每次新打开默认每日、详细、显示任务名称、隐藏心得。打开「显示每日与任务心得」后，两类心得按日期和更新时间排序，共用最近 8 条的上限；无任务的日子也可分享每日心得。详细卡最多展示 8 项任务，每条心得最多 100 字，长文字会省略；全部任务安排仍计入统计。简洁卡不含任务详情或心得。每日使用入口日期，最近 7 天以入口日期为最后一天；从记录页进入时以今天为准。
- 每日心得完全选填，最多 5000 字；空白的新心得不会创建记录，清空已有内容或点删除时需确认。每日心得不影响任务、打卡、完成率与专注；任务心得仍保存在对应打卡中，最多 1000 字。
- 允许系统通知后可使用计时通知及完成提醒。未允许系统「闹钟与提醒」权限时，手机休眠中的完成提醒可能延后；声音、振动遵循系统静音、勿扰和通知设置。
- 试听使用媒体音量，最多播放 10 秒；测试提醒不产生专注记录。兼容播放也使用通知音频用途和通知音量，遵守通知权限、静音、勿扰及频道设置，不强制增大音量。
- 若试听有声但测试通知无声，可检查「提醒状态」并尝试「兼容播放」，再查看诊断。用户已反馈 **1.4.0 在小米 14 上测试提醒与锁屏专注结束均有声音**；这是历史版本的使用反馈，不代表 1.12.1 已完成小米真机验证。
- 计划提醒遵循该任务的日期、星期、暂停与跳过状态；当天达标、归档或取消提醒后不再提醒。计划提醒与专注结束提醒各有设置，声音与准时程度仍受系统通知、勿扰及提醒权限影响。
- 自定义提示音最长 60 秒、最大 20 MB，最多保存 10 个。音频导入后保存在应用中，原文件移动也可继续使用；删除正在使用的自定义音频时，会切换回清晨铃。
- 计划备份包含进行中任务、归档任务及历史安排；记录备份包含打卡、任务心得、每日心得、已完成的专注及对应任务信息。计划备份不含每日心得。只导入记录不会新增每日待办，之后可导入相应计划。
- 「当前全部数据」的 JSON v8 文件保存当前任务、归档、个人资料与头像、自定义分类与图标、打卡、每日心得和已完成的专注；不含其他命名或自动存档、提示音、外观、首页布局、专注提醒、常用时长与上次手动时长。计划和记录合并导入会带入需要的分类，保留当前个人资料；恢复当前全部数据或阶段存档会恢复其中的个人资料。
- 「一键备份」ZIP 另包含命名与自动存档、自定义提示音、提醒、主题与首页布局、常用时长及上次手动时长，适合换机与完整保存。恢复前须结束当前专注；恢复会替换预览内容并清除旧的分类导入撤销副本。需要保留全部原内容时，先另存一份 ZIP。
- 恢复 ZIP v2、v3、v4、v5 时，本机今天的自动安全存档优先保留，再带回备份中的自动存档，总数最多 7 份。同一天不会被恢复后的数据立即覆盖。旧版 ZIP v1 没有自动存档，恢复时保留本机自动存档；旧文件未记录明暗模式时默认跟随系统。ZIP v1、v2 未包含配色，恢复时使用松绿；ZIP v1、v2、v3 未包含时长偏好，恢复为默认常用 15/25/45/60 分钟及手动时长 25 分钟。ZIP v1–v4 没有风格和首页设置，恢复为柔和、默认首页模块与顺序、详细密度及默认打开今日；v4 中已保存的配色与专注时长仍保留。
- 换肤只改变显示，不影响任务、记录、进度或提醒。「恢复默认配色」仅切换回松绿，保留当前风格与明暗模式。分类 JSON、命名存档和自动存档均不包含外观或首页布局，恢复这些数据时保留当前设置。
- 正在进行的计时、系统通知权限、系统频道设置与系统音量不随备份迁移；恢复后应发送测试提醒检查新设备设置。命名存档本身仍只保存该阶段的数据。
- 最多保存 50 份命名存档，每份名称最多 40 个字符。删除存档只删除该阶段快照。
- 自动存档独立保留最近 7 份，正常内容按日期轮替，仅损坏条目提供删除入口；空应用及仅修改昵称不会产生自动存档，每日心得、自定义分类或头像寄语等个人资料也属于可备份内容。它保存在应用内，换机或卸载前仍应导出完整备份。
- 备份提醒在应用内显示；点「稍后提醒」可选「明天提醒」或「7 天后提醒」，分别延后 1 天或 7 天。成功导出完整 ZIP 才重置备份日期，分类导出、查看存档、导入与恢复不会被当作已完成完整备份。
- 进行中的计划最多 200 个，含归档的历史版本最多 20000 个；打卡、专注记录与每日心得分别最多 100000 条。单份数据 JSON 最大 32 MB，一键备份内容总量最大 512 MB，实际容量也受心得和音频大小影响。

## 数据无法读取时

若启动后显示「数据需要恢复」，可直接选择：

- **从一键备份恢复**：选择 `.plan.zip`，校验并核对预览后确认恢复。
- **从本机存档恢复**：在「我的存档」或「自动存档」查看已有内容，再点「恢复此存档」。恢复模式不会提供新建、改名或删除原存档的操作。
- **从数据文件恢复**：选择包含全部当前数据的 JSON 文件，核对后替换恢复。若存在导入前安全副本，也可点「找回安全副本」。

恢复时会结束当前专注。原无法读取的文件会保留，具体可恢复内容以所选备份或存档的预览为准。详细步骤见 [使用指南](docs/使用指南.md)。

## 开发

仓库：https://github.com/james-kobe-curry/plan 。分支、提交、CI 与发布清单见 [开发与发布流程](docs/开发与发布流程.md)，产品决策见 [开发日志](docs/开发日志.md)。

原生 Kotlin + Jetpack Compose Material 3，minSdk 26，compile/target SDK 36。

环境：JDK 17 或 21、Android SDK 36、Gradle 8.14.3、AGP 8.12.0、Kotlin 2.1.20。

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest
```

Android Studio 打开本目录即可；`local.properties` 需要指向自己的 SDK，不应提交。

发布构建使用 `assembleRelease`。本机签名证书与配置保存在 `.signing/`，不包含在源码压缩包中。请单独保管该目录；后续覆盖升级需要沿用同一签名证书。

若本机全局 Gradle 缓存损坏，可以为构建追加 `--gradle-user-home .gradle-user` 使用独立缓存。
