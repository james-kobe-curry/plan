# plan 1.11.0 验证记录

验证日期：2026-09-16。上一版记录见 [1.10.0 验证记录](验证记录-1.10.0.md)。

## 本版变更

- 首页压缩个人信息与进度摘要，分享、心得仍可直接点击；今日安排的排序、折叠入口合入右侧更多菜单，大字体时标题与操作分行。
- 统一主要按钮为实色、次要按钮为浅底、辅助操作为文字，主要点击区域至少 48dp。柔和风格卡片/按钮/小控件圆角改为 20/14/10dp，减少装饰弧、粗边框和不必要宣传文字。
- 任务数量与单位放在同一行，保留方框打卡；置顶与跳过收进卡片更多菜单。完成勾选、背景与进度条使用轻微过渡，并按任务 ID 保留重排时的组件状态。
- 计划页前置新任务入口，整卡查看详情，编辑保留，暂停、延期和归档放入更多菜单。记录页使用紧凑统计、图表旁分享按钮与心得/月历/复盘三行导航。
- 分享窗口先显示常用选项与预览；点预览可查看大图，内容说明默认折叠，底部固定分享按钮。每次打开默认每日、详细，心得默认隐藏。
- 通用表单底部采用辅助取消与主保存，大字体时纵向排列；固定错误提示、键盘适配及草稿确认保留。
- 主标签页保存滚动与筛选状态。记录页首次等待概览完成后再创建滚动内容，避免加载中短页面把恢复位置顶回去；之后刷新保留已显示概览。
- 专注时间文字按圆盘可用宽度测量，适配大字体。任务、打卡、心得、提醒和备份规则未改变，仍为 JSON v8 / 完整 ZIP v5，默认柔和与原图标保留。

## API 36 模拟器验证

### 升级与数据

模拟器使用签名版 1.10.0 和既有测试数据建立基线，再覆盖安装 1.11.0。首次成功读取后文件与升级前逐字节一致，保留 15 个任务安排版本、7 条打卡、6 次专注、1 篇每日心得及个人资料和分类。

通过首页方框打开 LegacyWalk 的数量打卡窗口，点击完成目标并保存：当天新增一条 2 公里打卡（内部精度值 200），每日完成数由 1/12 变为 2/12，并显示完成提示。对比 JSON，只有该条打卡新增，其他计划、心得、专注、分类和资料字段均未改变。

### 首页与列表交互

- 首页明确显示换肤、分享、看心得、新计划和方框打卡；数量与单位同排，首屏可见第一张完整任务卡与第二张部分内容。
- 安排管理可进入排序，显示上下箭头与完成排序按钮，退出恢复通常列表。
- 已置顶任务的更多菜单包含取消置顶与跳过今天；点菜单未触发卡片打卡。
- 计划卡更多菜单包含暂停计划、归档任务。选择归档仍出现原确认对话框，取消后任务保留。
- 计划列表实际滚动后，切到专注再返回，界面可见文字和各自坐标逐项相同。
- 记录列表实际滚动后，切到专注再返回，界面可见文字和各自坐标逐项相同。

### 表单与大字体

- 新任务直接保存时，“请填写任务名称”固定显示在底部操作区上方。
- 启用模拟器软键盘，输入测试名称后保存和取消均显示在键盘上方，内容区独立滚动。
- 取消已修改内容时，仍提供放弃修改、保留草稿并退出、继续编辑；测试选择放弃，没有创建测试任务。
- 系统字体 2.0 倍时，首页个人区、安排标题与按钮自动分行；任务文字、方框打卡与圆环完整可读。
- 2.0 倍字体专注页的 25:00 完整显示，开始专注按钮可见。测试后系统字体恢复 1.0，软键盘硬件设置恢复原值。

- 分享窗口首屏可见每日/近 7 天、简洁/详细选择、预览、隐私开关和分享按钮。
