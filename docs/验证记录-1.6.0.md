# plan 1.6.0 验证记录

验证日期：2026-09-16。历史版本见 [1.5.0 验证记录](验证记录-1.5.0.md)。

## 本版修改

- 名称、分类、提醒时间立即更新；目标、单位或日程变化时保留当天已记录的进度及提醒，没有变化的保存不增加版本。
- 数量打卡分为「本次新增」与「修改当天总量」，预览保存结果。
- 任务与打卡表单支持草稿保留、放弃、重开继续；失效或保存结果未确认的草稿仅供查看复制，不自动重提。
- 记录页集中展示积累，右上角设置集中管理入口；大字体七日图可横滑，默认显示今天。
- 后台原子保存，多实例提交后刷新当前界面；跳过原因和恢复日期只在成功保存后关窗。
