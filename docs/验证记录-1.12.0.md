# plan 1.12.0 验证记录

验证日期：2026-09-16。上一版记录见 [1.11.0 验证记录](验证记录-1.11.0.md)。

## 本版变更

- 首页与计划页统一使用「新任务」，分类使用同一浅底、无描边控件，最小点击区域为 48dp。
- 打卡、跳过今天与暂停任务后提供短时「撤销」。撤销凭证在实际保存事务内捕获，只恢复该次修改，保留其他任务、其他日期记录、每日心得、资料与专注；同项记录或任务结构已变更时拒绝覆盖。导入与备份恢复会清除旧撤销入口。
- 详情与历史对话框也能直接显示撤销提示；忙碌弹窗不提供可点击撤销，保存与撤销同帧发生时会等待保存结束并重新检查凭证。提示按钮采用与当前主题匹配的高对比文字色。
- 首页、计划页、专注选择列表共用置顶、手动顺序、任务系列首次位置的规则。任务修订保留位置，完成后不自动沉底；折叠已完成继续可用。整理顺序仅在顺序发生变化并点击「完成排序」时统一反馈。
- 查看历史日期时，首页增加「正在查看」与「回到今天」入口，完成状态、进度标题及打卡文案对应所选日期；大字体时日期与返回按钮分行。
- 数据格式仍为 JSON v8 / 完整 ZIP v5，默认柔和风格和原图标保留。

- 首页 LegacyWalk 从未打卡保存为 2 公里，底部显示完成提示与撤销；点击后，完整数据对象与操作前一致。
