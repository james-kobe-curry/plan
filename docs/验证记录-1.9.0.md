# plan 1.9.0 验证记录

验证日期：2026-09-16。历史验证见 [1.8.0 验证记录](验证记录-1.8.0.md)。

## 本版修改

- 默认清简，另提供纸页、柔和风格；同时改变背景、圆角、标题字体、留白与装饰。六种强调色重新协调，色系不再大面积改变页面背景。
- 个人资料支持内置头像、相册头像、昵称、首页寄语与首页展示开关。
- 支持自定义分类的名称、图标、底色，以及任务独立图标；分类元数据改变不增加任务安排版本。
- 首页模块显隐和顺序、简洁/详细任务卡、默认打开页面可设置；任务列表始终保留。
- 移除复制任务入口及相关实现，已保存的副本仍作为普通任务保留。
- JSON v7 保存个人资料及分类，ZIP v5 保存风格与首页偏好；兼容旧 JSON v1–v6 和 ZIP v1–v4。

## 构建与自动测试

`:app:testDebugUnitTest :app:assembleRelease` 通过，34 个测试套件、411 项测试，0 失败、0 错误、0 跳过。发布构建包含 lintVital 检查。原复制功能的 15 项测试随功能移除，其余规则回归测试保留。

新版本重点覆盖：

- 三风格 × 六色 × 两种明暗模式，共 36 组颜色；正文对比度至少 4.5，图表对比度至少 3。
- 旧数据迁移、新分类/头像字段校验、分类删除保留所有计划和记录、即时元数据修改与旧草稿哈希兼容。
- 局部导入同名分类复用本机定义，保留本机颜色/图标；同 ID 异名分类重映射，重复导入与先记录后计划合并。
- 计划/记录导出包含关联分类，不包含个人资料；全部数据、命名存档和自动存档保留个人资料与分类。
- 首页顺序必须完整且无重复、任务模块不可隐藏、偏好逐字段回退；图片输入大小、像素尺寸与存储尺寸有界。
- ZIP v5 全部个性化往返、旧 v1–v4 默认迁移、缺失/非法偏好拒绝、写入失败和进程中断时完整回滚。
- 仅昵称变化延续原有空数据规则；有分类、头像或寄语时也会纳入自动存档保护。

自动测试中的故障注入和纯数据规则不代表均已在实体手机上执行。
