## 已确认的问题与修复

以下问题已修复，最终构建与执行结果见末节。

| 问题与触发条件 | 影响 | 本轮修复 |
| --- | --- | --- |
| 将同一任务修改目标后的计划备份，合并到仍保留旧安排的本机数据 | 旧版本因冲突保留，新版本又被新增，同一任务可能重复安排 | 按整个任务系列检查冲突、双活与历史区间重叠；保留本机完整系列，并在预览说明略过冲突 |
| 分类导入读取本机数据后，另一处存储操作恰好提交新记录 | 合并结果由旧快照生成，后续恢复可能覆盖刚保存的记录 | 使用共享存储锁内的读取、合并、安全副本和替换事务；补充确定性并发测试 |
| 主数据 JSON 损坏，但用户有完整 ZIP 或本机存档 | 原恢复门仅提供 JSON 文件入口，已有备份难以使用 | 补充 ZIP、数据文件、本机存档入口；恢复模式仅使用已有备份，处理遗留计时状态 |
| 提前开始未来任务、恢复未开始的归档，或旧备份中存在重叠版本 | 历史筛选代表可能仍标为归档，首页、复盘与进度卡可能计算不同 | 统一任务代表与按日期生效的版本选择；派生视图不删除、改写原任务和历史记录 |
| 操作提示仍存在时打开新的表单或窗口 | 提示条可能遮挡窗口底部操作 | 提示条仅在需要承接快捷撤销的详情／历史窗口显示，避免普通表单复用造成遮挡 |
| 计时偏好写入失败，内存状态已先更新 | 界面或后台可能继续启动／推进计时，重开后状态不一致 | 检查持久化结果，失败时恢复原内存状态并报告错误；服务、通知和完成确认须在成功保存后继续 |

计时写失败已在 API 36 模拟器复现并验证修复：旧版显示开始但未落盘；修复版提示操作未完成，仍可恢复权限后正常启动。新增 `FocusPersistenceTest` 同时覆盖返回失败、抛异常、回滚失败、完成／确认／重置失败以及恢复存储后的重试。

此外，完整 lint 检查发现 Android 8.0 不支持原主题中的导航栏属性。已将该属性移至 `values-v27`，API 26 保留适配的导航栏颜色；未通过忽略错误来绕过检查。损坏数据的恢复确认文案也已修正，不再承诺无法实现的直接撤销。

## 验证边界

- 逻辑单元测试不能证明系统通知一定准时或实际扬声器一定有声；通知权限、频道、静音／勿扰、厂商后台管理和音频解码需要 Android 环境确认。
- API 36 模拟器覆盖不能代替所有 Android 8.0 及以上系统、小米 14 真机、不同文件提供方和分享接收应用。本轮不将旧版“小米 14 有声”的用户反馈算作当前版本实测。
- 异常注入覆盖已列出的写入和恢复失败路径，不等于穷举所有设备掉电、存储介质损坏或极端内存情况。
- 本轮目标是确认现有功能及修复真实问题，没有据此新增功能或改动产品定位。“未再发现问题”仅限已执行的场景，不表示不存在任何缺陷。

### 本轮实际执行的 Android 场景

环境：独立 API 36 模拟器，1080×2400，默认字体；仅操作测试数据。先在 1.12.0 检查常规行为，再安装 1.12.1 复测修复路径；最终包再次安装并检查启动、数据保留和恢复确认。

- **任务与打卡**：全新安装显示柔和默认风格；空任务名称提示直接出现；只输入名称即可创建普通任务；打卡不写心得可完成，快捷撤销恢复未完成状态。
- **每日心得**：空白保存不创建记录；独立写入心得后完成率不变；存档里能只读查看心得。
- **草稿与表单**：输入任务名、保留草稿退出、重开恢复字段；放弃草稿；保存按钮没有旧提示条遮挡。
- **专注**：自定义 1 分钟；前台完成不自动打卡；暂停、进程重建、继续、锁屏完成与仅一次入账；注入持久化失败后回退及重试。
- **存档与备份**：命名、改名、预览；首次自动存档同日保持原内容；系统文件选择器导出完整 ZIP、预览恢复；旧版 ZIP 恢复后 15 个任务版本、7 条打卡、6 次专注、1 篇心得与备份对象完全一致，自定义音频及偏好保留。
- **损坏救援**：主文件损坏且遗留计时状态时可从完整 ZIP 恢复；另验证从本机自动／命名存档恢复。原件留存，恢复界面不能新建、改名或删除存档。
- **提示音**：内置四种声音列表、测试提醒诊断（通知提交、兼容播放启动和结束）；通过系统选择器导入 WAV、试听、删除当前音频后回到默认音。模拟器以无音频设备模式运行，只验证播放路径，不据此声称真机扬声器有声。
- **外观与分享**：柔和切换纸页、雾紫和深色，恢复默认配色；进度卡默认每日、详细且心得关闭；图片生成并打开系统分享面板。未发送给他人，未验证第三方接收应用。
