# plan 1.5.0 验证记录

验证日期：2026-09-16。本节记录最终发布包检查、自动测试和已完成的模拟器操作；尚未完成的检查单独列在验证范围中。

## 本版变更

- 增加任务可选提醒时间，按日期与星期安排提醒；通知支持 15 分钟后再提醒、今天不再提醒，提醒操作不改动打卡。
- 增加周复盘、月复盘，按当期有效安排汇总完成、未完成、跳过、暂停、专注与心得；当前阶段统计截止今天。
- 增加跟随系统、浅色与深色外观，外观偏好纳入完整 ZIP。
- 增加独立的每日自动存档，非空数据每天首次使用保存，保留最近 7 份；同一天不会覆盖已保存的安全快照。
- 增加应用内备份提醒，支持延后 1 天或 7 天，只有成功导出完整 ZIP 才重置导出日期。
- 完整 ZIP 使用 v2 格式，兼容读取 v1，增加自动存档与外观偏好；恢复时保留本机今天的安全存档。
