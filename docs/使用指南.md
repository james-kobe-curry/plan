# plan 1.12.1 使用指南

plan 帮助你安排学习、健身和日常任务，记录完成进度，使用专注计时，并通过月历、统计与进度卡回顾积累。

## 安装与升级

把 `plan-1.12.1.apk` 传到 Android 手机，点击安装。若系统询问，允许用于打开安装包的文件管理器安装应用。支持 Android 8.0 及以上。

本版版本号为 **16**，应用名称为 **plan**，保留原有图标与签名，可覆盖安装旧版。已明确选择的有效风格、色系与明暗模式继续保留。新安装或旧数据未选择风格时，默认使用柔和。升级前可先导出完整备份，无需卸载。

## 本版调整

- 合并计划时，同一任务的历史版本与当前安排如有冲突，会保留本机整个任务的安排，并在预览说明；导入与后台专注保存按同一事务顺序处理。
- 修正任务提前开始、归档恢复后的历史筛选状态；首页、复盘和进度卡使用一致的有效安排，旧记录继续保留。
- 数据无法读取时，可直接从一键 ZIP 备份、全部数据 JSON 或本机命名／自动存档恢复。
- 修正提示条遮挡新打开表单按钮的问题，详情和历史中的快捷撤销继续可用。
- 计时状态保存失败时显示错误并恢复原状态，避免将失败的操作显示为成功。
- 修正 Android 8.0 系统导航栏的兼容处理，默认柔和风格和原图标保持不变。

## 首页换肤

在首页点「换肤」，打开外观窗口。先选界面风格，再选择点缀色和明暗模式；每次点选立即生效并自动保存。

| 风格 | 界面特点 |
|---|---|
| 清简 | 中性底色、利落卡片、简洁标题和较紧凑的留白 |
| 纸页 | 暖纸底色、小圆角、书页式标题、细边线和横线 |
| 柔和（默认） | 适度圆角、轻盈留白、中性底色与少量点缀色 |

点缀色提供 **松绿、晴蓝、雾紫、柔玫瑰、暖杏、石墨**。主要背景和正文随风格保持协调，点缀色用于按钮、选中状态和少量重点；切换风格会同时改变卡片形状、标题排版、留白和细节。

- 「跟随系统」「浅色」「深色」与风格、点缀色分别设置。例如，可以同时选择纸页、晴蓝和深色，之后改为柔和仍保留晴蓝和深色。
- 「恢复默认配色」只恢复为松绿，不改变当前风格和明暗模式。
- 换肤不会改动任务、打卡、统计或提醒；原应用图标保持不变。
- 也可从「记录 → 设置 → 外观」打开同一个窗口。
- 进度卡会跟随当前风格、点缀色和明暗模式绘制。
- 首页进度圆环的数字和百分号缩小、分层显示；手机使用大字体时，圆环会按内容扩展，保留清楚的完成率。
- 新建、保存和开始专注使用实色按钮；编辑、打卡和分享入口使用浅底按钮；设置、排序等辅助操作更轻。主要操作保留清楚的文字与至少 48dp 点击区域，较大字体时按钮与内容按空间换行。

主题与首页布局随一键 ZIP 备份保存；分类 JSON、命名存档和自动存档不包含这些显示偏好。

## 个人资料与首页布局

### 头像、昵称与首页寄语

进入「记录 → 设置」，点顶部的个人资料卡片。

1. 选择内置头像，或点「从相册选择头像」选择图片；相册图片会裁成正方形并压缩后保存。需要时可移除相册头像，重新使用内置图标。
2. 填写昵称和首页寄语。昵称最多 30 个字，寄语最多 80 个字，可以留空。
3. 用「在首页展示个人资料」选择是否在首页显示头像、昵称与寄语，最后点「保存资料」。隐藏只改变首页显示，资料仍保留。

进度卡会使用昵称。个人资料与头像保存在当前全部数据、命名存档、自动存档和一键备份中；单独合并导入计划或记录时保留现有个人资料。

### 排列自己的首页

进入「记录 → 设置 → 首页布局」。

- 用上下箭头调整「今日进度」「任务列表」「最近积累」的顺序。
- 今日进度与最近积累可分别开关；任务列表始终显示。默认显示进度和任务，隐藏最近积累。
- 任务显示可选「详细」或「简洁」。简洁模式减少卡片留白，仍保留打卡、置顶与跳过操作。
- 默认打开页面可选「今日」「计划」「专注」「记录」，在下次启动时生效；点击提醒仍会打开对应页面。
- 点「恢复默认布局」后，可继续修改；点「保存布局」才保存本次布局。

布局和主题分别管理。调整首页不会改动任务、统计、提醒或个人资料。

在底部「今日」「计划」「专注」「记录」之间切换，再返回原页时会保留滚动位置，便于接着查看。首页「分享」「写心得」等常用入口仍可直接点击。

## 1. 添加任务

进入「计划 → 新任务」，填写任务名称，选择基础分类或自己建立的分类，按需选择任务图标，设置执行星期，点「保存任务」。默认每天执行，从今天开始；也可以选择其他开始日期。

计划页标题旁提供「新任务」，下方「管理分类」「备份与导入」用于管理已有内容。首页「今日安排」旁的「新任务」也可创建任务。

新任务无需填写时长或数量，例如「阅读」「练习英语」「运动」。完成后确认打卡即可。也可以点页面下方的「从模板开始」，再编辑自己的安排。

漏填名称、数量格式不正确或日期有误时，提示会出现在弹窗固定区域；即使滚动到表单下方，也能看到需要修改的内容。按提示修改后再次保存即可。

### 自定义分类与任务图标

可在「记录 → 设置 → 分类管理」建立分类，例如英语、考研、阅读。在任务编辑中选择需要的分类，也可进入管理分类。

- 学习、健身、日常三个基础分类始终保留；最多添加 20 个自定义分类，每个名称最多 16 个字。
- 每个自定义分类可设置名称、图标与底色；任务图标可选择「跟随分类」，也可单独指定。
- 首页和计划页可按分类筛选任务，使用一致的浅底按钮，点「全部」取消分类筛选；分类名称与图标也会显示在相关任务和回顾中。
- 删除自定义分类会把相关任务归回其基础分类，进行中、已归档的任务及全部记录继续保留。
- 分类和任务图标随相关计划、记录、全部数据及存档保存；合并导入会处理分类标识冲突，保留当前已有分类。

「复制任务」入口已移除。此前已保存的复制任务继续作为普通独立任务使用，已有进度与历史记录保留。需要继续原任务的积累时，可在归档页使用「恢复任务」。

### 草稿与退出

任务编辑字段、打卡数量和心得会自动保存为草稿。切到其他应用时也会保存当前输入。

- 有修改时关闭窗口，可以选择「保留草稿并退出」「放弃修改」或「继续编辑」。
- 再次打开新任务、同一任务的编辑窗口，或同一日期的打卡窗口，会恢复仍适用的对应草稿，并显示提示；这些草稿分别保存。
- 点「保存任务」或「保存打卡」并保存成功后才成为正式内容，随后清理草稿；正式保存失败时保留输入，可按提示修改后重试。
- 没有修改的表单不产生草稿。草稿不计入待办、打卡或统计，也不包含在任何正式备份、命名存档或自动存档中。
- 任务或当天记录变化后，不适用的旧草稿会隔离，不会直接填入表单。点「查看旧草稿」仍可查看、选取或复制文字，再按当前内容填写。
- 恢复一键备份、当前全部数据、阶段存档，或撤销上次导入前，会先隔离现有草稿。之后打开对应表单时，旧内容只供查看和复制，不会自动填入恢复后的数据。
- 如果应用在保存过程中中断，重开后提示「上次保存状态未确认」，请先核对正式任务或当天记录；这份草稿只供查看和复制，不会自动续填或再次提交，避免重复累加。

### 按需添加进度目标

需要记录具体进度时，打开「添加进度目标」，填写「每次目标」和「单位」。例如：

| 任务 | 可选目标 | 安排 |
|---|---|---|
| 英语学习 | 30 分钟 | 每天 |
| 专业课练习 | 20 题 | 工作日 |
| 阅读 | 15 页 | 每天 |
| 跑步 | 2.5 公里 | 周一、三、五 |
| 课程学习 | 1.5 小时 | 周末 |

小时、公里支持最多两位小数，例如 1.25 小时、2.5 公里；分钟、页、题、次等单位填写整数。不符合格式的输入会提示修改。

**更换单位会清空目标数量。** 无论输入新单位还是点快捷单位，都需要重新填写每次目标和已启用的总目标。例如把「30 分钟」改为「小时」后，应重新填写 0.5。再次选择同一单位会保留数量。

升级会保留原任务的目标与实际打卡数量；原有时间或数量任务不会自动变成普通任务。

### 开始日期、截止日期与总目标

- 「开始日期」决定从哪一天开始安排任务。
- 「添加截止日期（选填）」可限定计划持续时间，截止当天仍按所选星期安排；不需要时点「不设截止日期」。
- 开启进度目标后，可打开「设置总目标」，填写总数量。
- 填好起止日期与执行星期后，点「按执行天数分配每次目标」，将总目标分配到这段时间的执行日。

例如，在连续 30 天内每天阅读，共读 300 页，分配结果为每天 10 页。结果会按单位精度向上取整，也可以自行修改。

「我的计划」会展示总进度，累计该任务同一单位的打卡。编辑计划并重新分配时，会扣除已完成量，再按新安排生效日至截止日的剩余执行天数分配。修改单位前的记录仍保留，并按原单位显示。

### 修改什么时候生效

- 只改任务名称、分类、图标或提醒时间，保存后立即更新，不额外产生一版安排。
- 改目标、单位、执行星期或其他日程时，会保留之前的安排。该任务今天已有打卡，新安排最早从明天生效；今天尚无打卡时，最早从今天生效。更晚的开始日期按所选日期执行。
- 没有实质修改时，点保存不会增加历史版本。新目标和新单位不会反过来改变旧打卡。

### 按需设置计划提醒

在添加或编辑任务时，打开「设置提醒时间」，选择一个时间，例如 `08:30`，然后保存任务。不需要提醒的任务保持关闭即可。

- 提醒按该任务的开始日期、执行星期和截止日期安排；未安排的日子不会提醒。
- 当天达到目标、跳过今天、进入暂停期或归档后，不再继续当天的提醒。今天已有部分打卡时，暂停从明天起生效，今天仍按有效安排提醒；已到期任务不再提醒。
- 通知中的「15 分钟后」将这次提醒稍后再提示；「今天不再提醒」只停止当天提醒，后续执行日仍按安排提醒。
- **这些按钮不会修改打卡或自动完成任务。** 实际完成后仍在「今日」确认进度。
- 临时设置已经过去的时间，会从下一次有效安排开始提醒。

可在「记录 → 设置 → 计划提醒」查看通知与准时提醒的设置。按需允许 plan 发送通知及系统「闹钟与提醒」权限；声音遵循系统声音、通知与勿扰设置。计划提醒和专注结束提醒是两个入口，可分别调整。

## 2. 每天打卡

在「今日」找到任务，点击方框或任务卡片打开打卡窗口。

### 普通任务

确认「完成任务」，可填写「任务心得（选填）」，再点「保存打卡」。无需填写数量。误操作后可立即点底部提示的「撤销」；提示消失后，也可重新打开，点「撤销这次打卡」或取消勾选，再保存。

### 有进度目标的任务

默认选择 **「本次新增」**，数量框为空，只需填写这一次完成的数量。页面同时显示「当天已记录」和「保存后总量」，可核对后再保存。

- 上午已记录 10 页、下午又读 5 页，第二次填 **5 页**，保存后当天总量为 **15 页**。
- 要纠正当天总量，选择「修改当天总量」后填写最终数量。例如误记成 15 页，实际为 12 页，就填写 **12 页**。只改这项任务的心得时，也可使用这个模式保留原数量。
- 两种模式分别保留这次输入，来回切换不会把总量误当成新增量。
- 「完成目标」切换到总量模式，填入至少达到目标的数量；已经超额完成的数量不会被调低。仍需点「保存打卡」。
- 已记录部分进度时，按钮显示「继续打卡」；达到目标后显示「已完成」。两种状态都能重新打开修改。
- 「撤销打卡」将数量设为 0，保存后清除该日数量及心得。
- 超额完成会保留实际数量，进度条最多显示 100%。
- 保存时如果原任务或当天记录已发生变化，会提示重新打开确认；旧输入可以从草稿中查看，避免覆盖其他修改。

今日页可选择本周过去的日期；更早的记录使用月历查看。查看过去日期时，首页显示「正在查看」及具体日期，进度与完成文案对应当天；点「回到今天」返回当前日期。

### 快捷撤销上次操作

保存打卡、跳过今天或暂停任务后，底部会短暂显示结果和「撤销」。在提示仍显示时点击，可恢复这次操作前的状态。

- 打卡撤销会找回之前的数量和任务心得；若操作前没有记录，则移除本次新建的记录。独立每日心得不受影响。
- 跳过或暂停的撤销会恢复原安排与原有历史，不清空此前的打卡进度。
- **只撤销上次操作，不连续回退。** 如果对应记录、任务设置或相关状态之后已改变，会提示无法撤销，保留后续修改；其他任务与记录不会回退。
- 提示消失后，仍可从打卡窗口修改记录，在「已跳过」区域撤销跳过，或在计划中恢复安排。

### 跳过今天与整理列表

- 临时休息时点任务卡右上角的更多按钮，再选「跳过今天」，按需填写原因并确认。这一天不计入未完成，之后的安排照常；今天已有打卡时，需先撤销打卡才能跳过。
- 跳过的任务显示在「已跳过」区域，今天可点「撤销跳过」重新安排。任务详情会保留跳过日期和原因。
- 在任务卡右上角更多菜单中点「置顶」，让重要任务排在前面；再选「取消置顶」恢复普通位置。
- 点「今日安排」标题右侧的更多按钮，打开「安排管理」并选「整理顺序」。使用上下箭头调整任务，完成后点「完成排序」统一显示结果，移动时不反复弹出成功提示。置顶任务在置顶区域内排序；所选日期为今天时可排序。
- 首页、计划页与专注任务选择共用置顶和手动顺序。修改目标产生新版本时保留任务位置；完成打卡后也保留位置，可按需折叠已完成任务。各页仍按本身规则显示适用任务，筛选分类时调整顺序不会打乱其他分类任务之间的顺序。
- 在同一个「安排管理」菜单中选「折叠已完成」收起完成任务，需要查看时再选「展开已完成」。

### 独立的每日心得

每日心得记录这一天的感受，与某项任务的打卡心得分别保存。**完全选填，没写也不影响任务、完成率或专注记录。**

- 在首页点「写心得」；所选日期已有内容时显示「看心得」。每个日期最多一篇，每篇最多 **5000 字**。
- 输入后点「保存心得」。新内容留空时不会创建空白记录；离开尚未保存的编辑会询问继续编辑还是放弃修改。
- 在「记录 → 每日心得」按日期回顾；可搜索内容或日期，较长内容可点「展开全文」。
- 点「写今日心得」记录今天，也可点「选择日期」补写过去的日期；未来日期不能填写。
- 已有内容可点「编辑心得」修改，或在编辑窗口点「删除这篇心得」并确认。清空已有文字后保存同样会询问是否删除。
- 删除每日心得只移除那一天的独立文字，任务打卡、任务心得与专注记录继续保留。

任务打卡中的「任务心得（选填）」仍可使用，最多 1000 字；撤销该次打卡会移除相应任务心得，不会删除独立的每日心得。

每日心得会随记录备份、当前全部数据、命名与自动存档和一键备份保存；单独的计划备份不包含。分享进度卡时心得默认隐藏，主动开启「显示每日与任务心得」后才会加入分享。

## 3. 查看、补记和修改历史

进入「记录 → 全部记录与月历」。

### 按日期

1. 用左右箭头切换月份；点击月份标题，可快速选择日期。
2. 有打卡的日期下方显示小圆点。
3. 选择日期后查看当天任务，点任务打开打卡窗口，补记或修改进度、心得。
4. 右上角「今天」可返回当天。

只能为所选日期已安排的任务打卡，未来日期不能打卡。计划开始日期前或未安排的休息日不会自动生成任务。归档任务在其原有安排日期仍能查看；旧文件中与安排不一致的历史记录保留展示。

### 打卡明细与搜索

切换到「打卡明细」，按打卡日期从新到旧浏览完整记录。同一天按更新时间从新到旧排列，最近修改的记录排在前面。

- 在「搜索任务或心得」中输入关键词，可同时匹配任务名称和打卡心得。
- 点「全部任务」筛选某项任务，修改前后属于同一任务的记录会一起展示，保留各版的目标和单位。
- 用「全部」「本周」「本月」「自定义」选择日期范围。本周从周一到今天，本月从月初到今天；自定义范围包含开始和结束当天。
- 日期、任务和关键词可以组合使用。自定义开始日期不能晚于结束日期，错误提示会出现在弹窗固定区域。

点击记录可修改当天的进度和心得。刚修改的早期记录仍位于原打卡日期，不会被移到今天。

### 专注明细

切换到「专注明细」，查看每次完整专注的任务名称、完成日期、完成时间和实际时长。「自由专注」也会单独列出。

可按任务、任务名称关键词和日期范围筛选，顶部显示符合条件的次数与累计时长。完成日期与时间按当前设备的时区显示；这里用于回顾记录，不修改任务打卡。

## 4. 专注计时

从底部导航进入「专注」，选择任务或「自由专注」，再确认时长。

时间类任务会带入完整目标时长：

| 任务目标 | 专注时长 |
|---|---:|
| 30 分钟 | 30 分钟 |
| 1.5 小时 | 90 分钟 |
| 90 秒 | 2 分钟 |

不足整分钟的部分向上取整。带入时长按完整目标计算，例如目标 30 分钟、当天已打卡 10 分钟，仍带入 30 分钟。普通任务、页或题等非时间目标，以及自由专注，使用上次手动选择的时长；初始为 25 分钟。

可以点击常用按钮，也可以自定义 **1–1440 的整数分钟**。关联任务后仍可手动调整；切换页面再回来会保留设置。任务自动带入的目标时长不会覆盖上次手动选择。例如，手动选过 40 分钟，再选择目标为 90 分钟的任务会带入 90 分钟；之后选「自由专注」恢复为 40 分钟。

### 保存与管理常用时长

默认提供 **15、25、45、60 分钟**，可保留 **1–8 项**常用时长，按时长从小到大显示。

1. 点「自定义时长」，输入需要的整数分钟。
2. 勾选「保存为常用」，再点「确定」，同时设置本次时长并加入快捷按钮。
3. 需要移除时，点「常用时长」旁的「管理」，移除不常用的项目，再点「保存」。至少保留一项；重复添加已有时长不会产生重复按钮。
4. 在管理窗口点「恢复默认常用时长」，再点「保存」，可恢复 15/25/45/60 分钟。

点击常用按钮或确认自定义时长会保存手动选择，重新打开应用后仍可继续使用。移除常用项或恢复默认列表不会改变本次时长、上次手动选择或已有专注记录。计时运行或暂停期间，任务与时长保持锁定。

常用列表与上次手动时长会随一键 ZIP 备份保存；分类 JSON 和阶段存档不包含它们。

### 开始、暂停与结束

- 点「开始专注」开始计时，支持暂停与继续。
- 运行或暂停期间，任务与时长保持固定。需要修改时，先点「结束本次」，确认「结束并重置」。
- 完成一整段计时后计入专注统计；提前结束不计入。
- 允许系统通知后，可以在通知栏查看倒计时，并使用「暂停」「继续」「结束」。通知栏的「结束」会直接结束本次计时。
- 轻点计时或完成通知，可返回专注页面。

如果提示「专注状态未能保存」，请检查可用存储空间后重试。应用会保留原计时状态，不把本次未保存的开始、暂停、完成或重置当作成功；完成记录仍需成功保存后才确认。

专注与任务打卡分别记录。结束后回到「今日」，确认实际完成进度。

### 完成提醒

在「专注 → 专注提醒设置」或「记录 → 设置 → 专注提醒」中调整：

- **完成提醒**：开启或关闭完成通知。
- **提示声音**、**振动**：分别选择是否使用声音、振动，也可以全部关闭以静音提醒。
- **兼容播放**：通知已出现但系统没有播放声音时，可使用应用内的兼容播放。小米、Redmi、POCO 默认开启，其他设备也可手动开启。
- **提醒状态**：查看通知权限、当前提醒是否静默、手机响铃模式、通知音量及勿扰模式等状态。没有检测到静音设置时，也可以发送测试提醒确认实际效果。
- **当前提醒设置**：查看所选完成提醒在 Android 中的声音、振动及通知设置。
- **系统声音设置**：查看手机的响铃模式与音量。
- **应用通知设置**：打开 Android 的 plan 通知设置。
- **允许准时提醒**：需要时允许系统「闹钟与提醒」权限。
- **停止提醒声音**：立即停止正在进行或正在准备的兼容播放；通知上的「停止声音」也可使用。
- **查看诊断**：查看最近一次测试或专注结束时的触发时间、通知提交、播放器状态，以及品牌型号、Android 版本、通知音量与频道状态；可复制这些信息。

未允许「闹钟与提醒」时，手机休眠中的完成提醒可能延后。声音和振动遵循手机的静音、勿扰及通知设置。计时运行期间使用稳定的经过时间计算，调整手机日期或时间不会改变本次剩余时长。

### 选择与试听提示音

默认使用「清晨铃」，内置以下四种声音：

| 提示音 | 特点 | 时长 |
|---|---|---:|
| 清晨铃 | 明亮、清晰 | 2.8 秒 |
| 轻木琴 | 短促、利落 | 2.4 秒 |
| 清脆双音 | 两声提示 | 1.9 秒 |
| 柔和回响 | 舒缓、轻柔 | 3.6 秒 |

点声音名称或圆形选项即可选用，页面顶部会显示当前声音。每行右侧的播放按钮可单独试听；底部「试听当前」播放已选声音，再点「停止试听」即可停止。离开提醒设置后，试听会停止。

**试听使用媒体音量，最多播放 10 秒。** 完成提醒使用通知设置，两种音量可能不同。选好声音后，点底部「发送测试提醒」，确认实际通知的声音与振动；测试不会产生专注记录，发送后约 10 秒可再次测试。

如果试听有声、测试通知出现但没有声音：

1. 查看「提醒状态」，检查通知权限、通知音量、静音、勿扰和当前提醒设置。
2. 开启「兼容播放」，再次发送测试提醒。小米系列默认开启，若之前手动关闭过，可重新打开。
3. 如果仍无声，打开「查看诊断」，查看通知是否提交、播放器是否启动或被系统限制。可复制诊断留作排查，应用不会自动发送这些信息。

兼容播放仍使用**通知用途音频与通知音量**，不会强行调高音量，也不会绕过静音、勿扰、通知权限或频道静默设置。系统为提醒另行指定声音时，交由系统播放，避免两种声音同时响起。

用户已反馈：**1.4.0 在小米 14 上，测试提醒和锁屏专注结束都能听到声音。** 这属于历史版本的真实使用反馈，1.12.1 尚未据此完成小米真机验证。诊断中的“播放器已开始”表示播放调用已执行；实际效果仍以手机上听到的声音为准。

### 导入与管理自己的音频

1. 在「我的提示音」下点「导入音频」，通过系统文件选择器选择 MP3、WAV、M4A 等手机可播放的音频。
2. 音频需有可播放的音轨，最长 **60 秒**、最大 **20 MB**。超出限制时，可先截取需要的片段再导入。
3. 导入成功后，会保存并选用该声音；文件名称作为显示名称，可继续试听或发送测试提醒。
4. 最多保存 **10 个**自定义提示音。重复导入相同音频会使用已有条目，不重复占用名额。
5. 点音频右侧的删除按钮并确认，可移除该声音。删除当前选用的音频时，会切换回「清晨铃」；内置声音无需删除。

音频会复制并保存在应用中，之后移动或删除原文件不影响已导入声音的使用。导入失败时，原因会显示在页面底部的固定提示区域。

导入的提示音及提醒偏好可随「一键备份」ZIP 保存和恢复；单独的计划、记录、当前全部数据 JSON 和阶段存档不包含这些内容。卸载前请将需要保留的内容导出到应用以外的位置。

## 5. 统计与进度卡

「记录」依次展示打卡天数与累计专注、最近 7 天完成情况、历史入口和最近打卡。「每日心得」「全部记录与月历」「周复盘与月复盘」合并为一组导航行，点整行即可打开；「分享」位于「最近 7 天」标题旁。七日图表分别显示星期和日期，今天会标记为「今天」；休息日、跳过的日期和暂停期间不计入应完成任务。同一天的最近打卡按更新时间排序。

使用手机的大字体时，七日图表会增加每列宽度；屏幕放不下时显示「左右滑动查看 7 天」，初始展示最近日期。打卡天数与累计专注卡片也会按空间调整布局。

分享进度卡的方法：

1. 在首页点「分享」，或在「记录」的「最近 7 天」标题旁点「分享」，打开「分享进度卡」。每次新打开默认选择「每日」和「详细」。
2. 顶部可选择每日或 7 天范围、简洁或详细样式，随后直接查看图片预览。点图片可打开大图，较长的图片可以上下滚动，关闭大图后返回选项。
3. 详细样式可开关「显示任务名称」「显示每日与任务心得」，预览会随选择更新。心得默认隐藏，只有主动开启后才会加入本次分享。
4. 需要了解展示数量和文字省略规则时，展开「内容说明」；这部分默认收起。
5. 检查预览后点底部固定的「分享进度卡」，生成完成后打开 Android 系统分享面板，再选择需要使用的应用。

图片使用当前风格、点缀色与明暗模式。每次新打开默认每日、详细样式、显示任务名称、隐藏心得；简洁样式仅展示总览、完成进度与专注时长。

从今日页进入时，每日卡使用所选日期，最近 7 天以该日期为最后一天；从记录页进入时，以今天为最后一天。图片包含昵称、日期及生成时间。普通任务显示完成状态或完成天数，数量任务按原单位显示累计进度。

详细卡最多展示 **8 项任务**；每日心得与任务心得按日期、更新时间排序，**两类合计展示最近 8 条**，无任务的日期也可包含每日心得。任务名称最多显示 30 字，每条心得最多 100 字，长文字会省略；全部任务安排仍计入统计，原记录保持完整。每日心得不计入任务数、完成率或专注时长。关闭任务名称后使用「任务 1」等序号；同时开启心得时，心得中与已有任务名称完全相同的文字会替换为「该任务」，仍应按预览核对实际内容。

### 周复盘与月复盘

进入「记录 → 周复盘与月复盘」，选择「周复盘」或「月复盘」。用左右箭头查看其他阶段，点顶部「本周」或「本月」回到当前阶段。

页面展示完成率、已完成与未完成安排、跳过与暂停次数、打卡天数、专注次数与时长、分类回顾及当期心得。

- 周按周一开始，月按每月 1 日开始；当前周、当前月只统计到今天，之后的日子不提前计入未完成。过去的周和月按完整阶段回顾。
- 每项任务每天算 1 次安排，完成率为「已完成次数 ÷ 应完成次数」。休息日、跳过及暂停期间不计入分母。
- 已记录部分进度但尚未达到目标的任务仍属于未完成，页面会单独说明其中的部分进度。今天尚未完成的待办也暂列未完成。
- 没有应完成安排时，完成率显示「—」，不会把休息阶段显示成失败。
- 历史任务按当时的安排和目标统计。单独导入、当期没有对应有效安排的记录保留在打卡天数与心得中，不用来抬高完成率。
- 专注仍按完整结束的记录累计；复盘只用于回顾，不会改动原打卡或专注记录。

## 6. 归档与回顾

计划页分为「进行中」和「已归档」，可按名称搜索任务。点整张任务卡打开详情，查看任务安排、完成次数、打卡天数、累计专注与历史心得；卡片保留「编辑」，不再重复放置「查看」按钮。

任务结束后，在计划卡「更多 → 归档任务」确认归档。归档后不再继续安排；今天已有打卡则保留今天的统计。切换「已归档」即可随时回顾，原目标、单位、日期和心得仍会保留。

### 暂停、恢复与到期

- 暂时中断时，在计划卡「更多」中点「暂停计划」，也可从任务详情操作。暂停期间不产生每日待办，已有历史继续保留；误点后可在底部提示中点「撤销」。
- 如果今天已有打卡，暂停从明天起生效，今天仍可修改原进度；否则从今天起停止安排。
- 准备继续时在计划卡「更多」中点「恢复安排」，从今天按原星期安排；暂停期间不会补出未完成任务。
- 超过截止日期的计划显示「已到期」，在「更多」中点「延长截止日期」进入编辑，也可以选「归档任务」。

### 恢复归档任务

在「已归档」点「恢复任务」或在详情点「恢复这个任务」，选择恢复日期后保存。

恢复日期应为今天或之后，且不能与过去安排或已有打卡重叠。恢复会建立新的安排，之前的打卡、专注、心得和累计进度仍保留。原截止日期如果早于恢复日期，会清空；之后可在编辑中重新设置。已恢复的同一任务不能再次重复恢复。

任务曾经修改目标、单位或日程时，可在详情中展开各版安排。这类变化在今天没有打卡时最早从今天生效，今天已有打卡时最早从明天生效；更晚的开始日期按所选日期执行。名称、分类、图标和提醒则立即更新，不单独增加安排版本。

归档任务包含在计划备份、当前全部数据备份、一键备份和命名存档中。恢复后仍可在「已归档」回顾；月历和打卡明细也能查看相关记录。

## 7. 计划、记录与全部数据

从「记录 → 设置 → 数据与存档」进入，也可以点计划页标题下的「备份与导入」。页面分为「备份导入」「我的存档」「自动存档」三个页签。

### 一键打包备份与恢复

需要换机或完整保存时，在「备份导入」页点「打开一键备份」。一份 `.plan.zip` 文件包含：

- 当前计划、归档任务及历次安排，包括暂停、跳过、置顶和排序信息。
- 个人资料与头像、自定义分类与任务图标、打卡与任务心得、独立每日心得、已完成的专注记录和列表折叠偏好。
- 「我的存档」中的全部命名存档。
- 「自动存档」中保留的每日安全快照。
- 已导入的自定义提示音，以及声音选择、振动、兼容播放等提醒偏好。
- 主题风格、点缀色、明暗模式，以及首页模块顺序、显隐、显示密度和默认打开页面；任务提醒时间随计划保存。
- 专注的常用时长列表和上次手动选择的分钟数。

**导出：**点「准备一键备份」，核对任务、记录、存档、提示音数量和内容大小，再点「保存备份文件」，选择保存位置。

**恢复：**点「选择一键备份文件」，等待校验，核对恢复预览，再点「恢复这份备份」并确认替换。恢复前须结束当前专注；暂停中的计时也须结束。

恢复会替换当前计划、记录、个人资料与分类、全部命名存档、自定义提示音、提醒、主题与首页布局及专注时长偏好，并清除旧的分类导入撤销副本。**需要保留恢复前的全部内容时，请先另存一份 ZIP。** 恢复过程中保留安全副本；如果操作未能完成，应用会尝试还原原内容，必要时在启动页提示继续恢复。

自动存档有一项保护规则：**本机今天首次使用留下的安全存档优先保留**，再带回备份中的自动存档，总数最多 7 份。若备份里也有今天的自动存档，以本机今天的安全存档为准；恢复后的内容不会马上覆盖它。预览会说明这项规则。

本版一键备份格式继续使用 ZIP v5，包内当前数据与新建存档使用 JSON v8，包含独立每日心得；主题、首页布局、音频、提醒和专注时长偏好继续保存，仍可读取旧版 ZIP v1、v2、v3、v4。

- ZIP v1、v2 没有配色字段，恢复后使用松绿；未记录明暗模式时，恢复为「跟随系统」。ZIP v3–v5 保留文件中的配色与明暗模式。
- ZIP v1、v2、v3 没有专注时长偏好，恢复后使用默认常用 15/25/45/60 分钟，上次手动时长为 25 分钟。
- ZIP v1–v4 没有主题风格与首页布局，恢复后使用柔和、默认首页模块和顺序、详细密度及默认打开今日；旧 v4 中的自定义专注时长仍保留。
- ZIP v1 没有自动存档，恢复时会保留本机已有的自动存档。
- 旧 JSON v1–v7 尚无每日心得字段，读取后每日心得列表为空；旧 ZIP 内的数据按各自 JSON 版本读取。恢复完整数据会以备份内容为准，可先另存一份当前备份。
- ZIP v5 中已明确保存的清简、纸页或柔和风格继续使用，不会因为新版默认值变化而替换。

未保存的草稿、正在进行的计时、系统通知权限、系统频道设置与系统音量不包含在 ZIP 中。需要保留草稿内容时，先保存为正式任务或打卡，再导出备份。恢复到其他手机后，请发送测试提醒，检查该设备的通知与声音设置。

### 分类备份

在「备份导入」中，根据需要选择以下模块：

| 模块 | 保存什么 | 导入方式 |
|---|---|---|
| 计划备份与导入 | 进行中任务、归档任务、历次安排、自定义分类与图标，不含每日心得 | 合并到现有计划 |
| 记录备份与导入 | 打卡、任务心得、每日心得、专注记录、关联任务及其分类与图标 | 合并到现有记录 |
| 当前全部数据 | 当前任务、归档、个人资料与头像、自定义分类与图标、全部记录与每日心得 | 替换当前数据 |

### 导出文件

在所需模块点「导出备份」，通过系统文件选择器选择文件夹并保存。新文件扩展名为 `.plan.json`，内部应用数据使用 JSON v8，继续读取旧版 v1–v7。文件应保存在自己便于找到的位置，换机时可将它复制到新设备。

分类 JSON 文件不包含未保存的草稿、主题与首页布局、专注提醒偏好、常用时长与上次手动时长、导入的提示音、其他命名或自动存档和正在进行的计时。「当前全部数据」JSON 也保存个人资料、头像、自定义分类、任务图标和每日心得；需要连同全部存档和偏好保存时，请使用上面的「一键备份」。导入计划、记录或恢复阶段存档时，已有的提示音、主题与首页布局、专注时长偏好保持不变。

### 合并导入计划或记录

1. 在「计划备份与导入」或「记录备份与导入」点「导入」。
2. 选择对应的 `.plan.json` 文件，也可以选择「当前全部数据」JSON，从中提取所需内容。ZIP 使用独立的一键备份入口。
3. 核对预览中的新增、重复和冲突数量，再确认导入。

重复内容会略过；同一内容存在不同版本时，保留当前已有内容。相关自定义分类会随计划或记录一并带入，分类标识冲突时会重新关联，现有个人资料保持不变。记录导入也会合并每日心得；同一天内容相同则略过，内容不同时保留当前已有心得。导入前会显示实际处理结果，不会静默覆盖当前记录。

同一任务包含修改前后多版安排时，会一起检查。如果合并会让一个任务出现两个进行中版本，或历史日期重叠，会略过该任务的冲突安排，保留本机整个任务系列，并在预览中说明。其他无冲突任务仍可导入；无冲突的历史安排可补齐。

计划备份保留原开始日期、归档状态和历史安排。只导入记录时，会保留记录对应的任务名称、目标和单位，便于阅读历史，不会因此新增每日待办。之后导入相应计划，应用会尽量关联已有记录。

旧版 `.tongpin.json` 文件和完整备份也可使用。旧版纯计划模板按原有规则从今天开始安排；新版本计划备份保留原安排，导入预览会说明处理方式。

### 一起恢复全部数据

在「当前全部数据」点「导入」，选择保存全部当前数据的 JSON 文件，核对内容后确认替换恢复。当前计划、归档、个人资料与头像、自定义分类、记录和每日心得会切换为文件中的内容；正在进行的专注会重置。其他命名存档、自定义提示音、提醒、主题与首页布局、专注时长偏好不随这项操作替换。旧版数据文件未包含的个人资料与分类使用默认内容。

需要找回操作前的数据时，使用「撤销上次导入或恢复」。此功能保留最近一次操作前的副本，不能代替日常备份。

### 启动后提示「数据需要恢复」

如果当前数据无法读取，启动时会显示恢复入口。原文件会保留，可按手边已有的备份选择：

1. **「从一键备份恢复」**：点「选择一键备份文件」，选择 `.plan.zip`，等待校验并核对预览，点「恢复这份备份」后确认替换。
2. **「从本机存档恢复」**：进入「我的存档」或「自动存档」，选已有存档点「查看」，核对任务、记录与心得后点「恢复此存档」，再确认恢复。
3. **「从数据文件恢复」**：选择包含全部当前数据的 JSON 文件，核对预览后点「替换并恢复」。单独的计划或记录文件不能用于这项全部恢复。
4. 若存在上次导入前的安全副本，还会显示 **「找回安全副本」**，可确认找回操作前的数据。

恢复时会结束当前专注，内容以所选备份或存档为准。恢复模式只使用已有文件和存档，不提供新建、改名或删除原存档，也不会把无法读取的数据导出为空白备份。取消选择后可返回恢复入口，换另一份有效备份。

### 应用内备份提醒

首次有可备份内容满 7 天，且这段时间没有成功导出完整 ZIP，应用内会显示备份提示。成功保存一键备份后，从这次导出重新计算 7 天。

- 点「去备份」，打开一键备份入口，准备并保存 ZIP 文件。
- 暂时不方便时，点「稍后提醒」，选择「明天提醒」或「7 天后提醒」，分别延后 1 天或 7 天。
- 计划、记录、每日心得、自定义分类和头像寄语等个人资料属于可备份内容；仅修改昵称、尚无其他内容时不会因此开始提醒。
- **只有成功导出完整 ZIP 才重置备份日期。** 分类 JSON 导出、单个阶段存档导出、查看存档、导入及恢复都不算完整备份。

这是应用内的提示，不会自动替你创建外部备份文件。自动存档也不能代替换机或卸载前保存到应用之外的备份。

## 8. 我的存档

存档是一份有名称的阶段快照。例如，你可以分别保存「九月学习计划」「期末复习结束」「暑期运动记录」，以后打开回顾。

### 新建与查看

1. 进入「数据与存档 → 我的存档」。
2. 点「新建存档」，填写名称并保存。
3. 存档会保存当时的任务、已归档任务、个人资料与头像、自定义分类与图标、打卡与任务心得、独立每日心得及已完成的专注记录。
4. 点某份存档的「查看」，浏览当时的任务详情，或打开「查看这份存档的全部记录」；存档中的每日心得可单独打开回顾。

查看存档时，展示的是保存时的内容；后续打卡不会自动改写已保存的存档。若要保留新阶段，可以新建另一份存档。查看操作不会切换当前数据。

### 改名、导出与恢复

- **改名**：在列表点「改名」，为存档换一个便于查找的名称，原内容不变。
- **导出文件**：打开存档详情后点「导出文件」，把这一份存档保存为完整数据文件。可用「当前全部数据 → 导入」恢复，也可以分别导入其中的计划或记录。
- **恢复此存档**：核对后，用这份存档替换当前数据。恢复前保留可撤销的副本；其他命名存档保持原样。
- **删除**：删除列表中指定的存档，不删除当前正在使用的计划与记录。

最多保存 50 份存档，名称最多 40 个字符。若某份存档无法读取，会单独标记，其他存档仍可使用。

### 自动存档

在「数据与存档 → 自动存档」查看最近的每日安全快照。

- 有计划、记录、自定义分类或个人资料后，每天首次使用会保存一份当时的内容；空应用、仅修改昵称不会产生快照。
- 同一天再次打开或继续打卡，不会覆盖当天首次保存的内容。
- 独立保留最近 **7 份**，新的一天保存后自动轮替较早的快照，不占用 50 份命名存档名额。
- 点「查看」可回顾内容，在详情中「导出文件」或「恢复此存档」。查看不会改变当前计划；确认恢复后才会切换当前数据。
- 正常自动存档由应用轮替，只有无法读取的损坏条目提供删除入口。希望长期保留某一天的内容，可以先导出那份存档。
- 自动存档包含在一键 ZIP 备份中；恢复完整备份时，今天的本机安全存档优先保留，不会被马上重写。

**换机或卸载前，可使用一键备份将当前数据、命名与自动存档、提示音、提醒、主题与首页布局及专注时长偏好一起保存。** 也可按需导出单个存档。卸载会删除应用内的数据、恢复副本、各类存档和导入的提示音，请把导出的文件保存在应用之外。

## 9. 集中设置

进入「记录」，点右上角「设置」。这里集中管理个人资料、分类、数据、提醒、主题与首页布局；查看月历、周月复盘和最近打卡仍在「记录」主页。

| 设置入口 | 用途 |
|---|---|
| 顶部个人资料卡片 | 头像、昵称、首页寄语与是否在首页展示 |
| 分类管理 | 自定义分类名称、底色与图标 |
| 首页布局 | 首页模块顺序、显隐、显示密度与默认页面 |
| 数据与存档 | 一键备份、分类导入、命名与自动存档 |
| 计划与归档 | 查看进行中的任务与已归档计划 |
| 专注提醒 | 完成提醒、提示音、振动和兼容播放 |
| 计划提醒 | 任务提醒权限与系统设置；具体时间在任务编辑中设置 |
| 外观 | 三种风格、六种点缀色，以及独立的跟随系统、浅色或深色模式 |
| 使用说明 | 应用内功能介绍 |

- 在首页点「换肤」，或进入「记录 → 设置 → 外观」，先选择清简、纸页或柔和，再搭配松绿、晴蓝、雾紫、柔玫瑰、暖杏或石墨。点选立即生效并自动保存，无需另点保存按钮。
- 明暗模式可单独选择「跟随系统」「浅色」或「深色」。跟随系统会按手机的深色模式切换；手动选择后按自己的偏好显示，切换配色不改变这一选择。
- 「恢复默认配色」切回松绿，保留当前风格和明暗模式。
- 风格、点缀色、明暗模式与首页布局包含在一键 ZIP 备份中；恢复完整备份后随文件中的选择更新。分类 JSON、命名存档和自动存档不包含这些显示偏好。
- 在「设置」顶部点个人资料卡片，编辑头像、昵称、寄语与首页展示开关，点「保存资料」；进度卡和周报会使用新昵称。
- 「记录 → 设置 → 使用说明」可查看应用内功能介绍。

## 数据容量

进行中的计划最多 200 个，计划历史版本最多 20000 个，打卡记录、专注记录和每日心得分别最多 100000 条；每日心得每篇最多 5000 字。归档与修改产生的历史版本不占用进行中计划名额。

单份数据 JSON 最大 32 MB，一键备份所含内容总量最大 512 MB。记录条数、心得长度、存档数量与音频大小会共同影响实际容量。
