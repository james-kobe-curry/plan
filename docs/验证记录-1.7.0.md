# plan 1.7.0 验证记录

验证日期：2026-09-16。历史版本见 [1.6.0 验证记录](验证记录-1.6.0.md)。

## 本版修改

- 首页增加「换肤」入口，提供青绿、海蓝、鸢尾紫、玫瑰、暖橙、石墨六种配色。
- 配色与明暗模式独立保存，点选立即生效；恢复默认配色只恢复青绿。
- 配色窗口在大字体下改为单列，内容可滚动，完成与恢复默认按钮保持可见。
- 七日图表柱色、星期选中状态与页面配色一致。
- 一键备份升级为 ZIP v3，同时保存配色和明暗模式，兼容旧 ZIP v1、v2。任务数据格式仍为 6。

## 自动测试与构建

最终源码执行 `:app:testDebugUnitTest :app:assembleRelease` 成功，最终增量构建用时 **1 分 23 秒**。核对 27 份 JUnit XML：**330 项测试，0 失败、0 错误、0 跳过**；发布 lint 检查通过。

对测试列出的文字/背景组合要求对比度至少 4.5:1，图表/背景组合至少 3:1；该检查不代表所有系统界面、图片和设备均通过完整无障碍审计。文字阈值参考 [W3C 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

### 选色、持久化与大字体

- 从「今日 → 换肤」打开窗口，逐一选择六种颜色；检查浅色、深色及首页的实际显示。
- 选择石墨与深色，再恢复默认配色，回到青绿且保留深色。
- 选择鸢尾紫与深色，强制结束应用并重新打开，界面和实际偏好均仍为 `PURPLE / DARK`。
- 字体设为 1.6 倍后，配色列表变为单列；滚动可访问石墨与全部明暗选项，底部完成及恢复默认按钮可见。验证后恢复系统字体为 1.0 倍。

### ZIP 实际导出与恢复

1. 使用鸢尾紫与深色导出 `FullV17.plan.zip`。核对清单为 v3，设置包含 `PURPLE / DARK`，全部文件长度和 SHA-256 与清单一致；当前数据字节与升级前一致。
2. 备份中实际包含当前数据、1 份命名存档、1 份自动存档、1 首自定义提示音及其信息、应用偏好。
3. 改为玫瑰与浅色，经系统文件选择器导入刚导出的 ZIP 并确认恢复。成功后界面与偏好回到鸢尾紫与深色，当前数据 SHA-256 不变。
4. 实际导入并恢复 1.5.0 导出的 ZIP v2，默认配色回到青绿，保留备份中的深色模式。随后重新恢复本次 v3 备份。

旧 ZIP v1 的本次兼容性由自动测试覆盖，未在本次模拟器流程重复恢复。截图：[v3 恢复成功](../deliverables/screenshots/v1.7.0-full-backup-restored.png)。
